第6章：规划模式 (Planning)

来源 URL： https://adp.xindoo.xyz/chapters/Chapter%206_%20Planning/
整理日期： 2026-03-23

核心概念

规划（Planning）模式是指智能体在执行之前，先将复杂的高层目标分解为一系列有序的、可执行的子步骤，生成结构化行动方案，再按计划推进的能力。它将 AI 智能体从被动的反应式执行者转变为主动的目标导向策略者。规划并非预先固定的脚本，而是根据请求动态生成，并能在遇到障碍时（如首选方案不可用）重新评估并调整——这种适应性是规划模式的核心价值所在。

解决什么问题

复杂任务通常无法通过单一操作完成，而是需要多个相互依赖的步骤。若没有结构化规划，智能体面临：

  • 难以将高层目标分解为具体可操作的子任务
  • 无法管理步骤间的依赖关系和执行顺序
  • 在出现障碍时不知如何调整（如预订失败、资源不可用）
  • 导致结果不完整、不连贯甚至错误

何时用规划 vs 固定工作流？
关键判断标准：「方法」需要被发现，还是已经已知？

  • 方法已知且可重复 → 用预定义工作流（更可预测、风险更低）
  • 方法需要动态发现 → 用规划智能体（更灵活、能处理未知情况）

工作原理 / 关键机制

核心要素

要素 说明
目标解析 理解初始状态（预算、参与人数）和目标状态（成功完成事项）
计划生成 LLM 基于庞大训练数据生成合理有效的行动序列
依赖管理 识别子任务间的依赖关系，确定执行顺序
适应性 整合新信息、规避障碍，动态修订计划
工具编排 在计划执行中调用必要工具与外部系统

Google DeepResearch 的规划实现

  1. 将用户提示分解为多点研究计划，呈现给用户审阅修改
  2. 启动迭代搜索-分析循环：智能体动态制定和优化查询，而非执行预定义搜索列表
  3. 主动识别知识缺口，执行后续搜索填补
  4. 异步管理全流程，防止单点故障
  5. 批判性评估收集的信息，组织成结构化多页报告

应用场景

  1. 流程任务自动化

    • 新员工入职：分解为创建系统账户 → 分配培训模块 → 协调各部门的有序子任务序列
    • 业务流程编排：管理多步骤工作流中的依赖关系

  2. 复杂研究与报告生成

    • 竞争分析：自动收集市场趋势、竞品规格、公众情绪、营销策略，生成结构化报告
    • 学术探索：文献综述，追踪概念发展，识别研究前沿（如 Google DeepResearch）

  3. 机器人与自主导航

    • 生成路径或行动序列，从初始状态到目标状态
    • 优化时间/能源消耗，同时遵守环境约束（避障、交通规则）

  4. 结构化信息综合

    • 研究报告生成：信息收集 → 数据汇总 → 内容结构化 → 迭代完善的多阶段计划
    • 客户支持：创建诊断 → 解决方案实施 → 升级的系统计划

  5. 多步问题解决

    • 任何需要”先想清楚再做”的复杂任务，如法律文件分析、投资决策支持

框架实现

CrewAI

  • 规划能力嵌入在智能体的角色描述（backstory）和任务描述中
  • 通过明确要求”先创建计划，再执行”来触发规划行为

Google DeepResearch（Gemini）

  • 多步智能体流水线，动态迭代查询 Google 搜索
  • 计划生成后呈现给用户审阅，支持协作修改研究轨迹
  • 异步执行，支持用户脱离后台运行，完成时通知
  • 最终输出：结构化多页报告 + 完整来源列表 + 音频概述/图表

OpenAI Deep Research API

  • 透明度高：API 暴露中间步骤（推理过程、具体搜索查询、执行的代码）
  • 支持 MCP（模型上下文协议），可连接私有知识库
  • 高质量模型（o3-deep-research）vs 低延迟模型（o4-mini-deep-research）

对比

维度 CrewAI Google DeepResearch OpenAI Deep Research API
规划触发方式 提示词中明确要求 自动生成研究计划 自动分解为子问题
用户干预 无 计划可审阅/修改 无（程序化）
透明度 智能体日志 来源归因 完整中间步骤暴露
适用场景 可定制多步任务 复杂研究/竞争分析 企业研究自动化

注意事项与权衡

  • 灵活性 vs 可预测性：动态规划灵活但不可预测；固定工作流可靠但缺乏适应性
  • 计划可能过于乐观：初始计划可能低估复杂度，需预留调整空间
  • 执行漂移：长期规划中，智能体可能在执行中偏离原计划目标
  • 成本与时间：规划阶段本身消耗额外 LLM 调用；Deep Research 类系统可能耗时数分钟到数小时
  • 过度规划：对简单任务使用规划模式增加不必要复杂度，应评估任务复杂度后再决策
  • 选择偏差：即使迭代搜索也可能因查询选择引入偏差，需批判性看待综合结果

一句话总结

规划模式让智能体先”想清楚再动手”——将复杂高层目标动态分解为有序可执行步骤，在处理多步骤、多依赖的复杂任务（如研究报告、业务流程自动化）时，是连接人类意图与自动化执行的必要桥梁。
