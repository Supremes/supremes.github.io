# 算法刷题套路速记

> 口径说明：远程 `leetcode.db` 当前有 16 个题目分类（102 题），但 `/root/leetcode-tracker/app.py` 的 `/roadmap` `details` 只定义了 13 类可复用套路。额外的“数组 / 字符串 / 数学”更像基础载体或专项，解题时通常回落到哈希、双指针、滑窗、DP、模拟、数值边界等已有套路。

## 触发信号总表

| 触发信号 | 套路 | 核心结构 | 一句口诀 |
| --- | --- | --- | --- |
| “两个数和为 X”、找重复、计数 | 哈希 | `dict / set` | 配对找数 → 哈希 |
| 有序数组找配对、原地操作、两端逼近 | 双指针 | 左右/快慢指针 | 有序/原地 → 双指针 |
| 连续子数组/子串满足约束 | 滑动窗口 | 左右指针 + 计数器 | 连续子串 → 滑动窗口 |
| 区间和、子数组和为 K | 前缀和 | 前缀和 + 哈希 | 区间和 → 前缀和 |
| 题目给 `ListNode` | 链表 | `dummy` + 指针 | 链表题 → `dummy` + 快慢指针 |
| 题目给 `TreeNode` | 二叉树 | 递归 / BFS 队列 | 二叉树 → 递归三问 |
| 二维矩阵、连通块、依赖关系 | 图/网格 | BFS/DFS + `visited` / 入度 | 网格题 → BFS/DFS |
| 所有方案、排列、组合、切分 | 回溯 | 路径 + 选择列表 + 恢复现场 | 所有方案 → 回溯 |
| 有序、单调、答案可判定 | 二分 | 左右边界 + `check(mid)` | 有序/单调 → 二分 |
| 括号匹配、下一个更大/更小元素 | 栈 | 栈 / 单调栈 | 括号匹配 → 栈 |
| Top K、数据流最值 | 堆 | 小顶堆 / 大顶堆 | Top K → 堆 |
| 最少次数、最远距离、局部最优自然成立 | 贪心 | 一次遍历 + 当前最优 | 最少次数 → 贪心 |
| 最值/方案数，且贪心说不圆 | DP | 状态数组 / 滚动变量 | 最值方案数 → DP |

## 拿到题后的 60 秒决策树

1. **先看输入模型**：`ListNode` → 链表；`TreeNode` → 二叉树；矩阵/邻接关系/课程依赖 → 图/网格。
2. **再看题目载体**：数组别急着单开新类，先分有序/原地/区间/矩阵；字符串先看频次/窗口/回文；数学先看溢出/幂/开方/进制，通常只是把题面翻译成已有套路。
3. **再看答案形态**：所有方案 → 回溯；Top K / 数据流第 K → 堆；最值/方案数 → 先写 DP 状态；最少步数/覆盖范围 → 先验一下贪心。
4. **再看数据关系**：
   连续子串/子数组：
   - 求最长/最短/至多/至少 → 滑动窗口
   - 求“恰好等于 K”或有负数 → 前缀和
   有序/旋转有序/答案单调 → 二分；配对/去重/频次 → 哈希；原地搬运/两端收缩 → 双指针；括号/最近更大更小 → 栈。
5. **动笔前先写一句不变量**：例如：窗口内始终合法；`map` 存的是“值→下标”；`dp[i]` 表示前 `i` 个位置的最优；`check(mid)` 为真时答案在左半边。
6. **先拿样例空跑一遍**：3 步内跑不通，说明套路选错或不变量没写清。

## 数组 / 字符串 / 数学怎么回落

| 分类 | 先看什么 | 常见回落套路 | 远程 P0/P1 代表题 |
| --- | --- | --- | --- |
| 数组 | 有序、原地覆盖、区间、矩阵、Top K | 双指针、前缀和、栈、堆、图/网格、模拟 | `31 / 48 / 56 / 238 / 54 / 75` |
| 字符串 | 频次、窗口、回文、翻转 | 哈希、滑动窗口、双指针、DP、模拟 | `5 / 438 / 151` |
| 数学 | 溢出、快速幂、开方、进制/取模 | 模拟、二分、递归/分治、数值边界 | `7 / 50 / 69` |

- **数组**：`31 Next Permutation`、`48 Rotate Image`、`56 Merge Intervals`、`238 Product of Array Except Self` 都是数组题，但骨架分别更接近双指针/模拟、矩阵模拟、区间扫描、前后缀。
- **字符串**：`5 Longest Palindromic Substring` 可先想双指针中心扩展或 DP；`438 Find All Anagrams in a String` 直接回滑窗；`151 Reverse Words in a String` 回双指针/模拟。
- **数学**：`7 Reverse Integer` 先盯溢出；`50 Pow(x, n)` 回快速幂；`69 Sqrt(x)` 回二分。重点不是新套路，而是数值边界别写炸。

## 13 类套路速记

### 哈希

- **识别信号**：配对、频次、去重、首次出现位置、要把双重循环压成一重。
- **核心决策**：先问“我要记住什么键”。常见是 `值→下标`、`字符→频次`、`前缀和→出现次数`。
- **最小解题骨架**
  ```text
  初始化 map / set
  遍历每个元素 x
    若答案依赖“之前见过什么” → 先查再存
    若答案依赖“剩余还有什么” → 先统计全量再递减
  返回答案
  ```
- **P0/P1 代表题**：P0 [1. 两数之和](https://leetcode.cn/problems/two-sum/)；P1 [128. 最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/)
- **最容易犯的错误**：覆盖首个下标；查存顺序写反；连续序列没从“起点值”开始扩展。

### 双指针

- **识别信号**：有序数组找配对、原地去重/覆盖、两端收缩逼近最优。
- **核心决策**：每次移动某个指针，都要能证明“不会错过答案”。
- **最小解题骨架**
  ```text
  指针放在两端 或 fast/slow 两位
  while 条件成立
    根据当前关系移动一个或两个指针
    若要原地写回，把 slow 当作“下一个有效位置”
  ```
- **P0/P1 代表题**：P0 [283. 移动零](https://leetcode.cn/problems/move-zeroes/)；P1 [11. 盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/)
- **最容易犯的错误**：循环边界少等号；去重时没跳过重复值；写回后指针推进顺序错。

### 滑动窗口

- **识别信号**：连续子串/子数组 + 最长、最短、至多、至少。
- **核心决策**：先定义“窗口什么时候合法”，再决定何时右扩、何时左缩。
- **最小解题骨架**
  ```text
  left = 0
  for right in [0..n)
    把 nums[right] 纳入窗口
    while 窗口不合法
      移出 nums[left]
      left++
    用当前窗口更新答案
  ```
- **P0/P1 代表题**：P0 [3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)；P1 [76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/)
- **最容易犯的错误**：窗口非法时只缩一次；计数归零不清理；更新答案的时机放错。

### 前缀和

- **识别信号**：区间和、子数组和为 K、想把区间枚举从 `O(n^2)` 压到 `O(n)`。
- **核心决策**：遇到“恰好等于 K / 统计个数”，优先写出 `pre[j] - pre[i] = k`。
- **最小解题骨架**
  ```text
  map[0] = 1
  pre = 0
  for x in nums
    pre += x
    用 map[pre - k] 更新答案
    map[pre]++
  ```
- **P0/P1 代表题**：P0 [560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)；P1 暂无（远程库当前未标）
- **最容易犯的错误**：忘记初始化 `map[0]`；“求个数”和“求最长”混用同一含义；有负数时误用滑动窗口。

### 链表

- **识别信号**：题目给 `ListNode`、删除/插入、局部翻转、倒数第 N 个、成环。
- **核心决策**：头节点可能变化就先上 `dummy`；涉及倒数、中点、成环就先想快慢指针。
- **最小解题骨架**
  ```text
  dummy -> head
  找到 pre / slow / fast
  改 next 前先保存 next
  只改局部 3~4 根指针，再整体推进
  返回 dummy.next 或目标节点
  ```
- **P0/P1 代表题**：P0 [206. 反转链表](https://leetcode.cn/problems/reverse-linked-list/)；P1 [19. 删除链表的倒数第N个结点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)
- **最容易犯的错误**：改指针前没存 `next`；删头结点没用 `dummy`；快慢指针间隔 `N` 的边界少走一步。

### 二叉树

- **识别信号**：题目给 `TreeNode`、深度/路径/祖先/遍历/层序。
- **核心决策**：递归前先回答三问：函数返回什么、向子树要什么、在哪一层更新答案。
- **最小解题骨架**
  ```text
  dfs(node)
    if node == null: 返回基线
    left = dfs(node.left)
    right = dfs(node.right)
    用当前节点合并 left / right
    返回给父节点的值
  ```
- **P0/P1 代表题**：P0 [236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)；P1 [98. 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/)
- **最容易犯的错误**：把“返回值”和“全局答案”混成一个；BST 校验只比较父子；层序遍历忘了按层固定 `size`。

### 图/网格

- **识别信号**：矩阵连通块、最短步数、课程依赖、图克隆。
- **核心决策**：最短步数优先 BFS；依赖无环优先拓扑；连通块计数 BFS/DFS 都行，但必须先标记再扩展。
- **最小解题骨架**
  ```text
  准备方向数组 / 邻接表 / 入度表
  遍历所有起点
    连通块题：入队/递归，并立即标记 visited
    拓扑题：先收集入度 0，再逐层削减邻居入度
  统计答案
  ```
- **P0/P1 代表题**：P0 [200. 岛屿数量](https://leetcode.cn/problems/number-of-islands/)；P1 [207. 课程表](https://leetcode.cn/problems/course-schedule/)
- **最容易犯的错误**：`visited` 标记太晚导致重复访问；行列边界写错；拓扑排序没统计处理节点数。

### 回溯

- **识别信号**：所有方案、排列、组合、切分、子集。
- **核心决策**：排列看 `used`；组合看 `startIndex`；要去重时先分清“同层去重”还是“同枝去重”。
- **最小解题骨架**
  ```text
  dfs(状态, path)
    if 命中终止条件
      收集答案并返回
    for choice in 当前可选集合
      做选择
      dfs(下一状态, path)
      撤销选择
  ```
- **P0/P1 代表题**：P0 [46. 全排列](https://leetcode.cn/problems/permutations/)；P1 [39. 组合总和](https://leetcode.cn/problems/combination-sum/)
- **最容易犯的错误**：排列和组合混用 `used/startIndex`；撤销不完整；剪枝条件放错层级。

### 二分

- **识别信号**：有序数组、旋转有序、峰值、答案空间单调。
- **核心决策**：先定你找的是左边界、右边界，还是满足条件的最小答案；核心是写清 `check(mid)`。
- **最小解题骨架**
  ```text
  left, right = 搜索边界
  while left < right
    mid = left + (right - left) / 2
    if check(mid) 为真
      right = mid
    else
      left = mid + 1
  最后按题意校验 left
  ```
- **P0/P1 代表题**：P0 [35. 搜索插入位置](https://leetcode.cn/problems/search-insert-position/)；P1 [34. 在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)
- **最容易犯的错误**：区间定义没统一；`mid` 写法导致死循环；边界题一找到值就提前返回。

### 栈

- **识别信号**：括号匹配、表达式求值、下一个更大/更小元素。
- **核心决策**：先定栈里存“值”还是“下标”；单调栈里，弹栈那一刻就是旧元素答案被确定的时刻。
- **最小解题骨架**
  ```text
  初始化栈
  遍历每个位置 i
    while 栈非空 且 当前元素触发结算
      弹栈并更新答案
    压入值或下标
  必要时收尾处理剩余元素
  ```
- **P0/P1 代表题**：P0 [20. 有效的括号](https://leetcode.cn/problems/valid-parentheses/)；P1 [739. 每日温度](https://leetcode.cn/problems/daily-temperatures/)
- **最容易犯的错误**：单调栈存值导致算不出距离；括号映射方向写反；相等元素的处理条件不统一。

### 堆

- **识别信号**：Top K、流式第 K 大、动态最值。
- **核心决策**：第 K 大通常用“小顶堆保留 K 个最大值”；中位数才考虑双堆。
- **最小解题骨架**
  ```text
  初始化小顶堆
  遍历每个元素 x
    push(x)
    if 堆大小 > k
      pop()
  答案通常在堆顶
  ```
- **P0/P1 代表题**：P0 [215. 数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)；P1 暂无（远程库当前未标）
- **最容易犯的错误**：第 K 大用错堆方向；忘了限制堆大小；误以为堆内整体有序。

### 贪心

- **识别信号**：最少次数、最大覆盖、每步自然有一个“当前最好”的选择。
- **核心决策**：先证明“此刻这样选永远不吃亏”；证明说不圆，就回退想 DP、二分或图。
- **最小解题骨架**
  ```text
  维护当前最优状态
  遍历每个位置/区间
    更新最远可达 / 最低成本 / 当前收益
    到达提交边界时，结算一次选择
  ```
- **P0/P1 代表题**：P0 [55. 跳跃游戏](https://leetcode.cn/problems/jump-game/)；P1 [122. 买卖股票的最佳时机 II](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/)
- **最容易犯的错误**：只背结论，证明不出局部最优；边界结算时机错；把“可行性”题写成“最优值”题。

### DP

- **识别信号**：最值、方案数、计数，且重复子问题明显；贪心难证明。
- **核心决策**：先写一句人话状态定义，再写转移、初值、遍历顺序；不会时从“最后一步发生了什么”倒推。
- **最小解题骨架**
  ```text
  定义 dp[i] / dp[i][j] 的含义
  写出初值
  按依赖顺序遍历状态
    dp[当前] = 若干旧状态转移而来
  返回目标状态
  ```
- **P0/P1 代表题**：P0 [198. 打家劫舍](https://leetcode.cn/problems/house-robber/)；P1 [322. 零钱兑换](https://leetcode.cn/problems/coin-change/)
- **最容易犯的错误**：状态定义含糊；初值漏掉空数组/第一行第一列；一维压缩后把旧值提前覆盖。
