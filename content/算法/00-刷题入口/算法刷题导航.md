## 4 周顺序

### W1：手感恢复

- 顺序：哈希 → 双指针 → 滑动窗口 → 前缀和 → 栈
- 同步处理基础分类：数组题先看“有序 / 原地 / 区间 / 矩阵”，分别回落到双指针、前缀和、栈、图/网格或模拟；字符串题优先看哈希 / 滑窗 / 双指针；数学题只补整数溢出、快速幂、开方边界，必要时回到二分或递归。
- 热手代表题：数组先刷 `31 / 48 / 56 / 238`，字符串先刷 `5 / 438 / 151`，数学先刷 `7 / 50 / 69`；它们是专项入口，不单独扩成第 14-16 套路。
- 前缀和放 W1：它和滑动窗口都在处理连续区间；遇到“恰好等于 K”或数组含负数，就从窗口切到前缀和。
- 目标：把“配对 / 有序 / 连续 / 括号”四种信号练成条件反射。
- 最低要求：哈希、双指针、滑窗各过一题 P0；前缀和至少过 `560`；栈至少过括号题和一个单调栈题。

### W2：结构题

- 顺序：链表 → 二叉树 → 图/网格
- 目标：恢复 `dummy`、快慢指针、递归三问、BFS/DFS/拓扑三套骨架。
- 先链表后树：两者都是指针题，但树更依赖递归抽象。
- 图/网格只抓三件事：连通块、最短步数、依赖关系。

### W3：搜索与选择

- 顺序：二分 → 回溯 → 堆 → 贪心
- 目标：先练单调性，再练“所有方案”，最后补 Top K 与局部最优。
- 二分先统一区间写法；回溯只背“选 → 递归 → 撤销”；堆先记“小顶堆保 K”；贪心先证明当前选择不吃亏。

### W4：DP 收口

- 顺序：DP
- 目标：把“状态定义 → 转移 → 初值 → 遍历顺序”说顺。
- 如果 W1-W3 某类还反复卡壳，先补那类 P0/P1，再回到 DP；不要硬顶多维状态。

## P0 → P1 → P2 规则

1. **P0**：先做模板题，只求 20-25 分钟内能独立写出骨架，并口述时间/空间复杂度。
2. **P1**：只有当同类 P0 能稳定过边界，再进变种题；不会就回看 [算法刷题套路速记](../01-套路速记/刷题笔记.md)。
3. **P2**：只做加分题或你的短板题；默认 1-2 题封顶，不让它吞掉主线时间。
4. 每完成一类，都按 **P0 回刷 → P1 查漏 → P2 选做** 的顺序复盘，不跳级。

## 每天 60-90 分钟最小闭环

1. **5-10 分钟**：复盘 D-1、D-3、D-7 的错题，只看触发词、失误点、边界。
2. **20-30 分钟**：做 1 道当周新题；先口述套路，再动手写。
3. **15-20 分钟**：卡住就翻 [算法刷题套路速记](../01-套路速记/刷题笔记.md)，再按面试语言选择 [Java 模板](../02-代码模板/Java刷题模板.md) 或 [Python 模板](../02-代码模板/Python刷题模板.md)，把最小骨架默写一遍。
4. **10-15 分钟**：补 2-3 个边界样例，确认复杂度、判空、下标、去重、负数场景没写反。
5. **5-10 分钟**：写 3 行复盘：题型信号 / 第一次写错点 / 下次看到什么词直接想到它。

## 1 / 3 / 7 天复习节奏

- **Day 1**：次日重做同类 1 题，不看答案，优先默写骨架。
- **Day 3**：只看题面，30 秒内说出套路、不变量、复杂度；说不出来就回炉 P0。
- **Day 7**：混做 2-3 题，检验是否还能在不同题面里认出同一套路。
- Day 7 仍卡壳，就不要升级到下一优先级，继续留在当前类的 P0/P1。

## 面试执行顺序

1. **识别套路**：先判断是哈希、窗口、链表、树、图、二分、回溯、堆、贪心还是 DP。
2. **口述复杂度**：开写前先说目标复杂度，以及为什么不用暴力。
3. **写模板**：先把最小骨架敲出来，再补题目细节。
4. **过边界**：空输入、单元素、重复值、越界、负数、环、空指针至少过一遍。
5. **复盘**：记录触发信号、不变量、第一次写错的位置，不抄长代码。

## 使用边界

- 本区以 `/roadmap` 的 13 类套路为主线，并补数组 / 字符串 / 数学的映射说明；代码模板只维护 Java 与 Python 两种面试语言，不再扩写长题单或完整题解。
- 新题优先落到“哪一类、什么优先级、错在哪”，而不是继续堆报告长度。
