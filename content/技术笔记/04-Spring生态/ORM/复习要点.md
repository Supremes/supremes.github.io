# Hibernate

- 全ORM框架：基于JAVA对象的领域模型，建立了Java对象（POJO）与数据库表之间的完整映射关系（通过注解或XML）
	>  操作Java对象时，hibernate会根据映射关系，在运行时自动生成并执行SQL语句(HQL或Criteria API最终会转为SQL)
- 基于JPA规范
- JPQL -> HQL：hibernate方言，功能语法基本重叠
- 延迟加载
- 关联映射
- N+1问题：善用@ManyToOne/@OneToMany的FetchType.LAZY，避免N+1查询
- 一级、二级缓存
- criteria api
- 复杂查询，可结合使用原生SQL查询 - `createNativeQuery`

# Mybatis/Mybatis-Plus

**半自动，SQL映射框架**
- 核心：SQL与Mapper接口的映射
- 条件构造器 Wrapper- `LambdaQuery/UpdateWrapper`, 组装各种where条件
- 编写SQL（写在XML或注解里），MyBatis将SQL执行结果，灵活映射到Java对象
- Mybatis -> Mybatis-Plus: 默认集成了CRUD能力

**拓展功能**
- 乐观锁 `@Version`
- 逻辑删除 `@TableLogic`
- 动态表名: 配置拦截器 - `DynamicTableNameInnerInterceptor`
