# Agent 架构面试专题导航

这套目录按领域分成五个文件，每个文件里再按专题分节。每个专题回答三个问题：

1. 这一层负责什么，不负责什么？
2. 工程上怎么实现，失败时怎么定位？
3. 面试时拿什么项目证据支撑？

## 建议复习顺序

### 第一轮：先讲清 Agent 怎么跑

01.运行时 从头到尾 → 02.知识系统。

目标是能从用户输入开始，口述一次完整 Agent Loop，并解释工具结果如何回到模型。

### 第二轮：再讲怎么上线

03.生产化 从头到尾。评测 → 可靠性 → 沙箱 → 安全 → 性能，其中「重试怎么落到 Trace」要能和评测那节的 Trace 数据模型对上；沙箱与安全分开理解执行限制和业务授权。

目标是能设计一套带数据集、Trace、CI 门禁、权限控制和故障恢复的生产系统。

### 第三轮：准备项目追问

04.协作与路由 → 05.面试实战。

目标是准备两段有数据的项目经历。每段都要说清约束、取舍、失败和复盘。

## 每个专题的完成标准

- 能用 30 秒说出职责边界。
- 能画出核心数据流或状态机。
- 能回答 5 个高频追问。
- 能列出 3 个常见错误与风险，并给出定位证据。
- 有一个真实项目例子，不用假设数据。
